## Regras

**Nomes de arquivo** com data e descrição, sem espaços nem acentos: `2026-09-30-simulacao-wokwi.png`.

**Tamanho:** o GitHub recusa arquivos acima de 100 MB e fica lento com muitos arquivos grandes. Comprima fotos antes de enviar (até cerca de 1 MB cada). Vídeos longos devem ir para o YouTube ou Google Drive, com o link registrado em `videos/README.md`.

**Pessoas nas imagens:** só publique fotos de pessoas com autorização delas. Para menores de idade, a autorização é dos responsáveis.
